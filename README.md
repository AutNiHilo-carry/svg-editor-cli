# SVG 编辑器 CLI

Lab1 Phase 1，使用 TypeScript 面向对象实现。

## 开发

需要 Node.js 22 或更新版本。

```sh
npm install
npm run check
npm run build
npm test
npm run cli
```

Windows PowerShell 若限制执行 npm.ps1，可使用 `npm.cmd` 代替 `npm`。

目前完成项目初始化和领域模型：六种图形、嵌套容器、画布与 ID 约束，以及移动、缩放、属性设置。启动入口仍仅输出骨架状态，尚未实现命令交互。
