## 架构核对

使用 TypeScript 语法树检查 54 个模块文件（不含组合入口 main.ts），共 49 个类、175 处导入：

- 每个模块文件最多一个类，类名与文件名一致；未发现顶层自由函数声明。
- domain 无外层业务模块或外部库依赖。
- application 仅依赖本层和 domain；文档存储端口属于 application。
- commands 仅依赖本层、application 和 domain，不直接使用终端、文件系统或 XML 库。
- cli 通过 commands 执行操作；infrastructure 依赖 application/domain 并实现存储接口。
- CommandDispatcher 和 ShapeFactory 两个注册表集中处理命令名和类型名分派；图形操作通过多态实现。
- Command、Composite、Memento 和存储依赖倒置均有实际代码，架构方案已记录工厂迁移和快照策略修订。

该静态检查覆盖导入和类声明约束，不等同于所有运行行为的形式化证明。

## 检查中修复的问题

1. XML 文本中的 `&#13;` 回车保存后会被读取规范化为换行。现在将序列化结果中的裸回车编码为字符引用，回车、换行与制表符往返后保持原值。
2. 文本含 XML 禁用控制字符时，原序列化器会生成不合法文件。现在启用严格 XML 序列化，保存失败时保留原文件和命令历史。
3. `doc/README.md` 中“需检查依赖”和“final 标签待创建”等状态已经过时，已更新为实际完成情况，并补充本检查记录链接。

前两项均先增加回归测试复现失败，再完成修复；测试由 32 项增加至 34 项。

## 支持边界与交付

- 外部 SVG 只支持六种内置标签；path/defs/tspan、百分比及其他长度单位、DOCTYPE 明确拒绝。
- 导入的 transform、viewBox、字体等属性会保留；编辑作用于元素本地坐标，未实现变换矩阵展平或自动布线。
- 几何缩放保持字号和描边宽度样式；历史使用完整内存快照，尚未针对超大文档优化。
- 反馈文字和属性排版与需求示例可能不同；错误前缀、命令语法与关键状态语义按测试核对。
- 本轮在上述 Windows 环境执行，未声称完成 Linux/macOS 或所有字体环境的验证。
- 代码与文档推送至 GitHub，`final` 标记包含本轮修复和记录的最终交付版本；查看具体提交应以该标签为准。
